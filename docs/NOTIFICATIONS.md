# Kept — přehled notifikací

Vygenerováno z `Kept/Services/NotificationTemplates.swift`. Celkem 188 textů.

Zástupné znaky: `{task}` = název úkolu, `{time}` = čas, `{why}` = tvoje „Proč na tom záleží“, `{n}` = počet, `{days}` = délka série („5 dní“).

## Jak se texty vybírají

- Každý tón má strop, jak ostrý text smí použít: **Normální** nejvýš „Přímé“, **Přísný** nejvýš „Přísné“, **Drsný** až „Drsné“.
- Příprava a start úkolu jsou ve všech tónech stejné a věcné.
- Ostřejší text přichází postupně: po začátku, při deadlinu a po něm. Kritická priorita, opakovaná selhání stejného úkolu a dodržené sliby pod 60 % posunou text o stupeň výš (nejvýš po strop tónu).
- V drsném tónu má vyhrocená připomínka a souhrn během dne jako **nadpis** jednu z úderek; věta o úkolu je pod ní.
